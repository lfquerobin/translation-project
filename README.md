# Projeto de Tradução

Guia para criar e manter projetos de tradução literária para o português brasileiro. Cada obra ou versão em trabalho tem seu próprio repositório, com os textos, as fontes, o glossário e o registro das revisões.

- [Guia editorial e de criação de projetos](AGENTS.md)
- [Índice de projetos](projetos/README.md)

O guia reúne práticas adotadas e verificadas no trabalho com Re:Zero. As convenções de uma obra ficam no seu próprio repositório e podem variar conforme a edição, os idiomas e a forma de publicação.
